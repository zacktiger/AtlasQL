# What the API needs to serve. Not what the ETL needs to build the database.
#
# Nothing on the serving path imports geopandas, rasterio, rasterstats, shapely,
# pyogrio or pandas — those belong to the import jobs, which run once against a
# database and are not part of a deployed app. Splitting them out takes the
# container from roughly 1.2 GB to under 200 MB and removes the GDAL/GEOS/PROJ
# build from every deploy. The geometry the API serves is computed by PostGIS
# inside the database, which is why the app itself needs no geospatial stack.
#
# Use requirements.txt instead for anything that runs `python -m atlasql.cli`.
